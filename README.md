# Battle Guys Reloaded

**A Ghost Saves™ project by Petty**

Battle Guys Reloaded is a community revival and preservation project for the classic **Battle Guys**.

The goal is simple: bring the original game back online and preserve it for the future.

## Features

* Original Battle Guys client support
* Recreated backend services
* Multiplayer restoration
* Game data preservation
* Reverse engineering & research
